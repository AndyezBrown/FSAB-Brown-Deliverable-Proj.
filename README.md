# 1. Overview

A To-Do List Website. Can add and delete tasks with fields: 1. Task Name 2. Due Date 3. Urgency 4. Task Type. 


## 2. How to run it

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
